## Core Philosophy

> Do not hardcode strategy logic. If you find yourself writing a rule like
> "only trade during London session" or "exit after 8 bars" — stop. That decision
> belongs to the data and the model, not to us.

All strategy parameters live in `DISCOVERED_PARAMS` (generated by `ml/config_generator.py`,
never hand-edited). Only `HARD_CONSTRAINTS` in `config.py` are human-defined.

## Hard Risk Constraints

| Constraint | Value |
|---|---|
| Risk per trade | 0.5% account equity (tiered: 0.3% <£5k, 0.5% <£10k, 0.7% above) |
| Max risk per trade | £50 GBP hard cap |
| Max trades per instrument per day | 1 |
| Max open trades forex | 3 |
| Max open trades indices | 2 |
| Max open trades total | 4 |
| Daily drawdown kill switch | −3% |
| Intraday re-entry cooldown | 2 hours |
| Re-entry confidence floor | 70% (first trade of day has no floor) |
| No weekend holding (forex) | Friday 21:00 UTC |
| Index EOD close | Session end (SPX/NAS 21:00 UTC, DE30 16:30 UTC) |
| OANDA environment | `practice` only — never change without explicit sign-off |

## Position Sizing

Units are **float rounded to 2dp** — OANDA accepts fractional units for all instruments
including indices. Previous bug used `max(1, int(...))` causing index trades to breach £50 cap.

```python
# usd_quote: EUR_USD, GBP_USD, AUD_USD
units = round(risk_gbp / sl_distance_price, 2)

# usd_base: USD_JPY, USD_CHF
units = round((risk_gbp * gbpusd_rate) / (sl_distance_price / entry_price), 2)

# usd_index: SPX500_USD, NAS100_USD
units = round((risk_gbp * gbpusd_rate) / sl_distance_points, 2)

# eur_index: DE30_EUR
units = round((risk_gbp * gbpeur_rate) / sl_distance_points, 2)
```

JPY prices: 3dp. All others: 5dp.

## Dashboard DB (Supabase aureyn-acieral)

```
Tables: bots, trades, equity_snapshots, news_events, news_status
```
- All tables have RLS enabled with postgres full-access policy
- Bot writes via `ACIERAL_DB_POOL_URL` (psycopg2, bypasses RLS)
- Dashboard API reads via `ACIERAL_DB_URL` (port 5432 direct)
- `trade_type`: `'backtest'` (seeded history) / `'practice'` (live bot) / `'live'` (future)
- Max drawdown uses only `source='practice'` equity snapshots
- Monthly returns use first equity snapshot of each month as denominator

### DB Integration Points (bot writes)
- `register_bot()` — on bot startup
- `write_equity_snapshot()` — on startup, daily reset, every 30 min, after every trade close (5 paths)
- `write_heartbeat()` — every 30 min
- `write_trade()` — on trade open, on trade close (all paths), on reconcile restore
- `reconcile_db_trades()` — on startup and daily reset
